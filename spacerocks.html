Description

A modern clone of the classic arcade game Asteroids — pilot your ship, blast drifting space rocks, and dodge the debris.

SpaceRocks is a native macOS game written in Swift with SpriteKit.

Features

  • Arcade action — fast-paced asteroid blasting.
  • Flexible controls — play with the keyboard or a game controller.
  • Hazards and defenses — shields, alien UFOs, and more.
  • Retro style — visuals and sounds that nod to the original cabinet.
04

Getting Started

SpaceRocks requires macOS 13.0 or later. Install the latest release with Homebrew:

brew tap kdekorte/SpaceRocks https://github.com/kdekorte/SpaceRocks.git
brew trust kdekorte/SpaceRocks
brew install --cask spacerocks

On first launch, open System Settings → Privacy & Security and allow the app to open.
