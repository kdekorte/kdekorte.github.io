Description

A GW-BASIC interpreter that brings the classic 1980s programming language back to life — parse, run, and relive vintage BASIC code.

Basika is a small IBM BASICA-compatible interpreter written in C on top of SDL3. It runs classic line-numbered programs in the terminal or in a graphics window, and adds QBasic-style modular programming plus a handful of modern extensions for images, fonts, and compression.

Features

  • BASICA compatibility — a wide range of IBM BASICA commands, with a full keyword and syntax reference in KEYWORDS.md.
  • Modular programming — QBasic-style SUB and FUNCTION blocks with CALL, DECLARE, SHARED, STATIC, local scope, pass-by-reference parameters, and recursion.
  • Graphics — an SDL3 graphics window (-w) or a headless virtual framebuffer for CI, with image handles via _LOADIMAGE, _PUTIMAGE, and _FREEIMAGE.
  • Fonts — load and switch TrueType fonts with _LOADFONT, _FONT, and _FREEFONT, and draw Unicode text with _UPRINTSTRING.
  • Sound — SOUND and PLAY with the Music Macro Language, plus sound files (WAV, OGG, MP3, or FLAC) through the _SND commands.
  • Strings — heap-backed dynamic strings that handle multi-megabyte values, fixed-length STRING * n declarations, and lossless _DEFLATE$ / _INFLATE$ compression.
  • Files — sequential, random-access, and binary file I/O, with QBasic's variable PUT and GET on TYPE records.
  • Tested — a make test suite plus a performance regression guard that times a two-second benchmark of the interpreter's hot paths.
05

Getting Started

On macOS, install with Homebrew. The SDL3 dependencies are pulled in for you:

brew tap kdekorte/basika https://github.com/kdekorte/basika.git
brew install basika

To build from source you need gcc, pkg-config, and the SDL3, SDL3_ttf, SDL3_mixer, and SDL3_image development headers. Then run make.

Running programs

./basika demo/hello.bas            # run in the terminal
./basika -w demo/boing_ball.bas    # open a graphics window
./basika --headless demo/hello.bas # virtual framebuffer, no window
./basika demo/sound_demo.bas       # SOUND and PLAY demo

Development Notes

2026-11-06

Version 0.99.9 brings QBasic's variable PUT and GET to file I/O, string-heavy loops that run three to four times faster, array loops about twice as fast, numbered timer event traps, and Unicode text through _UPRINTSTRING. A wide patch of QB64 Phoenix Edition — the math, bit, file and folder, clipboard, mouse and window functions — arrived this cycle, and the Homebrew formula and the Burrow cask are updated to match.

2026-10-21

PUT #n, position, variable and GET #n, position, variable now accept any variable, as in QBasic — numeric and string scalars, array elements, and TYPE record members — instead of only whole records and the len, data$ form, which keeps working. BINARY files move exactly the variable's bytes, so PUT #1, 1, x% writes 2 bytes instead of crashing, and a GET past the end zero-fills. RANDOM files move a whole LEN-byte record and report Bad record length when the data is larger, and an omitted position reads or writes just past the last one, as QBasic does.

2026-10-20

String assignment and concatenation got faster: the expression parser appends variable values, STRING$ and SPACE$ directly into the result and hands its finished buffer to the caller, and assignments and parameter bindings adopt a temporary's buffer instead of copying it — only what BASICA value semantics requires still copies. String-heavy loops run about three to four times faster. A new demo runs a .bas file as a shell script: give it a #!/usr/bin/env basika shebang line and the execute bit, and ./demo/os_shebang_demo.bas works like any other script.

2026-10-19

A day of speedups. Variable names are cached and statement dispatch is threaded so loops run faster, PAINT and PSET share a pixel cache, and event traps are no longer polled when nothing is pending. Array loops got their own boost: an expression of a single name or number, such as a(i) = i, is compiled and cached like longer expressions instead of being re-parsed on every iteration — the sieve benchmark dropped from 6.5 to 3.3 seconds for 10 million elements.

2026-10-19

Added QB64 timers and process control. _FREETIMER hands out a free timer number, ON TIMER(t, n) GOSUB arms a trap on it, and TIMER(t) ON, OFF, STOP, or FREE controls it, alongside the classic ON TIMER(n). _EXIT is -1 on the first read after the user closes the window, and SHELL gained the _HIDE and _DONTWAIT options, plus _SHELLHIDE(command$), which runs the command hidden and returns its exit code.

2026-10-18

Text can now be Unicode. _UPRINTSTRING draws UTF-8, UTF-16, UTF-32 or codepage text at pixel positions, _UPRINTWIDTH, _UFONTHEIGHT, _ULINESPACING and _UCHARPOS measure it, _MAPUNICODE maps code points, _CONTROLCHR with OFF makes PRINT draw control codes as glyphs, and _BLINK keeps its setting.

2026-10-18

QBasic's one-line procedures work: SUB P: PRINT G: END SUB and FUNCTION SQ (X): SQ = X * X: END FUNCTION, with or without a line number — before, the procedure ran on through the rest of the program. Inline declarations arrived too, as in FreeBASIC: DIM n AS LONG = 1000000 sets a variable's first value and FOR i AS LONG = 1 TO n declares the loop counter's type, and both work with OPTION _EXPLICIT.

2026-10-18

The window, mouse and images filled out. _SAVEIMAGE writes PNG, JPG, BMP, TGA, GIF, ICO and WEBP files, _HSB32 builds colors from hue, saturation and brightness, and _SETALPHA, _CLEARCOLOR and the palette functions round out the images. The window gained _TITLE$, _SCREENMOVE, _SCREENHIDE and the _DESKTOP functions, the mouse gained _MOUSESHOW with cursor styles and _MOUSEMOVE, and the metacommands $INCLUDE, $INCLUDEONCE, $IF/$ELSE, $LET, $SCREENHIDE and $SCREENSHOW are processed — before, every $IF branch ran.

2026-10-18

The QB64 system functions arrived: _OS$, _UPTIME, _COMMANDCOUNT, _ERRORLINE, _ERRORMESSAGE$, the lock keys, _KEYCLEAR and _CLIPBOARD$, which reads and sets the clipboard — before, each read as a plain variable. The VS Code extension now highlights .bas files too, with a grammar generated straight from the lexer's keyword tables.

2026-10-16

Basika now has a demo video, and it's built by basika itself. Each demo runs headless and saves every frame with SCREENSHOT, small scripts drive the mouse through Paint and Jukebox, and Vortex and Burrow play themselves on autopilot. A Python script draws the title cards in the IBM VGA font and synthesizes the soundtrack, and ffmpeg joins the clips and adds a CRT glow and scanlines. Also fixed a crash when an expression ends in an operator, such as PRINT 1 +; it now reports a syntax error, as QBasic does.

2026-10-16

A large batch of QB64 Phoenix Edition functions arrived: the math set — _MIN, _MAX, _CLAMP, _CEIL, _HYPOT and _ATAN2, plus the hyperbolic and reciprocal trig families and the degree, radian and gradian conversions; the bit set — _SHL, _SHR, _ROL and _ROR; and the string set — _TRIM$, _BIN$, _INSTRREV, _STRCMP and _STRICMP. QB64 functions now get their arguments with their types instead of as doubles, so large _INTEGER64 values stay exact, and _ROUND returns an integer, as in QB64. The file and folder functions were added too — _FILEEXISTS, _DIREXISTS, _DIR$, _CWD$, _STARTDIR$, _FULLPATH$, _FILES$, _READFILE$ and _WRITEFILE — before, each read as a variable, so IF _FILEEXISTS(f$) THEN was always false. The five performance benchmarks became one two-second check whose baseline stays put, and the 3D wave demo now turns its surface around the Y axis instead of drawing it once.

2026-10-15

Text now uses the real IBM PC screen fonts (VGA 8×16, EGA 8×14 and 8×8), scaled only by whole numbers so every glyph is pixel-exact, and the window draws sharp on Retina displays instead of being blurred up from half resolution. PRINT spacing between numbers now matches QBasic, ? works as shorthand for PRINT, and KILL is silent. A new Life demo runs Conway's Game of Life on a 160×120 grid, with cells that fade in and out and can be drawn with the mouse.

2026-10-14

Version 0.99.8 can package a BASIC program as a standalone Mac app. A build script bundles a portable basika, SDL3 and its libraries, the fonts, and the program's assets into a signed .app, and Burrow is now installable as a Homebrew cask. A new Jukebox demo plays songs from a mouse-driven list and keeps play counts in a random-access file of TYPE records, and Vortex got a synthwave music loop and joystick support.

2026-10-13

Added Burrow, a Dig Dug-style digging game with original sprites, sounds, and an autopilot title demo. It uses the new QB64 sound file commands: _SNDOPEN loads WAV, OGG, MP3, or FLAC, and _SNDPLAY, _SNDLOOP, _SNDPAUSE, and _SNDPLAYCOPY control playback. FREEFILE was added, and EOF now returns -1, so the common DO WHILE NOT EOF(n) loop works. A VS Code extension can now run .bas files with basika.

2026-10-13

A round of graphics speedups. More expressions are compiled ahead of time, POINT reads from a cached copy of the image, and PAINT presents once a frame and uploads only the area it filled instead of waiting on the display after every fill. _DISPLAY now turns automatic presents off, as it does in QB64. New regression tests and benchmarks cover expressions, POINT, and PAINT.

2026-10-09

Version 0.99.7 ships with Vortex, a Tempest-style tube shooter in BASIC. Flippers, tankers, and spikers climb the lanes of six tube shapes, and the game has a superzapper, warps between levels, and a demo game on the title screen. Getting it to run meant fixing loop control inside procedures: EXIT FOR actually works now (it used to be ignored), EXIT SUB from inside a loop no longer leaks loop entries, and a single-line IF ... THEN ... ELSE in a procedure runs only one branch.

2026-10-08

A pass with macOS leaks found and fixed memory and resource leaks in SELECT CASE, INPUT$, ENVIRON, and in image and font slots left over after RUN, CHAIN, or NEW. The paint demo now draws thick rectangle and oval outlines at the brush size, and no longer overflows on fast strokes in large windows or leaves striped gaps in filled circles.

2026-10-08

Basika can now run more QB64 programs as written. OPTION _EXPLICIT checks that every variable is declared before the program starts, $NOPREFIX lets QB64 keywords drop their leading underscore, and _FULLSCREEN, _PRINTMODE, _ROUND, and DIM AS type name lists are supported. _LOADFONT gained bold, italic, and underline styles, and the printstring demo was rewritten as an animated text and font showcase.

2026-10-08

Windows can be resized with $RESIZE and _RESIZE, and the paint demo grows to fill the window or shows scroll bars when the window is smaller than the picture. PRINT USING now matches QBasic field by field, and Boing Ball draws at full 1024×768 resolution with time-based motion at up to 60 fps.

2026-10-07

Arithmetic moved to QBasic's rules. Integer variables hold exact 64-bit values, expressions carry their QBasic type and raise Overflow when a result doesn't fit, and operator precedence matches QBasic. A single token-based expression parser replaced the old text evaluator. Arrays can be passed to procedures as name(), with LBOUND and UBOUND, and EQV, IMP, CINT, CLNG, CSNG, and CDBL were added.

2026-10-07

Added QB64's image, mouse, and keyboard extensions: _NEWIMAGE, _DEST, _SOURCE, _COPYIMAGE, a QB64-compatible _PUTIMAGE with stretching and mirroring, _KEYDOWN, _KEYHIT, and the _MOUSE functions. They are put to work in demo/qb64_paint.bas, a MacPaint-style program that includes its own --selftest.

2026-10-07

A long list of classic commands arrived: LINE INPUT, WRITE, PALETTE, screen pages with PCOPY for double buffering, CHAIN with COMMON, STOP/CONT, WAIT with a simulated VGA retrace, and direct-mode SAVE, LOAD, RENUM, AUTO, and EDIT. Random-access files now follow QBasic's record layout and error codes.

2026-10-07

Graphics commands now take QBasic's argument lists: CIRCLE arcs and ellipses, LINE style masks, PAINT tiles, and STEP everywhere. Alpha moved to the QB64 model, with SCREEN _NEWIMAGE(w, h, 32) and &HAARRGGBB colors, replacing the trailing alpha arguments from last week. DIM ... AS type, LONG, and &H/&O/&B literals were added, and the BASICA benchmark got about 25% faster.

2026-10-06

Added CONST, POINT, CSRLIN, and POS. The interpreter now steps to the next statement through the program list instead of rescanning from the top and caches procedure lookups, which cut Boing Ball's headless frame time from about 88 ms to 34 ms.

2026-10-03

Version 0.99.6 brought much more QBasic-style structured programming: full SELECT CASE blocks (value lists, TO ranges, CASE IS comparisons), every form of DO...LOOP with EXIT DO, multiline IF/ELSEIF blocks, and user-defined TYPE records with arrays and random-record file I/O.

2026-10-03

Numeric expressions are now compiled when a program loads, and procedure variable lookups are cached. The 10-million-iteration basica.bas benchmark dropped from about 1.17 s to 0.65 s. A pre-commit hook now guards against performance regressions.

2026-10-03

PLAY gained foreground/background playback, articulation modes, volume, and tempo control, and PSET, LINE, and PAINT now take optional alpha values. A new --no-audio flag keeps automated tests fast.

2026-10-02

Version 0.99.5: errors in programs without line numbers now report the real source-file line. Side-effect-free DEF FN bodies compile once to an AST, cutting a 2-million-call benchmark from 0.99 s to 0.64 s.

2026-09-23

Added QBasic SUB and FUNCTION procedures with local scope, recursion, pass-by-reference and pass-by-value parameters, plus CALL, DECLARE, SHARED, and STATIC.

2026-09-01

Strings moved to heap-backed storage that grows on demand, so multi-megabyte values work. Fixed-length STRING * n declarations were added, and _DEFLATE$/_INFLATE$ handle large round trips.

2026-08-19

Added _LOADIMAGE, _PUTIMAGE, and _FREEIMAGE on top of SDL3_image, and improved _LOADFONT rendering with crisp nearest-neighbor glyphs.

2026-07-06

Line numbers became optional. Programs can now jump to named labels, and WINDOW and VIEW provide logical coordinates and viewport clipping for every drawing command.

2026-06-17

Added a --headless mode so graphics programs and screenshots can run in CI, and refactored the interpreter core and variable lookups for a 2× speedup.
