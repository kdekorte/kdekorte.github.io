Description

A GW-BASIC interpreter that brings the classic 1980s programming language back to life — parse, run, and relive vintage BASIC code.

Basika is a small IBM BASICA-compatible interpreter written in C on top of SDL3. It runs classic line-numbered programs in the terminal or in a graphics window, and adds QBasic-style modular programming plus a handful of modern extensions for images, fonts, and compression.

Features

  • BASICA compatibility — a wide range of IBM BASICA commands, with a full keyword and syntax reference in KEYWORDS.md.
  • Modular programming — QBasic-style SUB and FUNCTION blocks with CALL, DECLARE, SHARED, STATIC, local scope, pass-by-reference parameters, and recursion.
  • Graphics — an SDL3 graphics window (-w) or a headless virtual framebuffer for CI, with image handles via _LOADIMAGE, _PUTIMAGE, and _FREEIMAGE.
  • Fonts — load and switch TrueType fonts with _LOADFONT, _FONT, and _FREEFONT.
  • Sound — SOUND and PLAY with the Music Macro Language.
  • Strings — heap-backed dynamic strings that handle multi-megabyte values, fixed-length STRING * n declarations, and lossless _DEFLATE$ / _INFLATE$ compression.
  • Tested — a make test suite plus a performance regression guard built around a 10-million-iteration benchmark.
04

Getting Started

On macOS, install with Homebrew. The SDL3 dependencies are pulled in for you:

brew tap kdekorte/basika https://github.com/kdekorte/basika.git
brew install basika

To build from source you need gcc, pkg-config, and the SDL3, SDL3_ttf, SDL3_mixer, and SDL3_image development headers. Then run make.

Running programs

./basika demo/hello.bas            # run in the terminal
./basika -w demo/boing_ball.bas    # open a graphics window
./basika --headless demo/hello.bas # virtual framebuffer, no window
./basika demo/sound_demo.bas       # SOUND and PLAY demo

Development Notes

2026-10-03

Version 0.99.6 brought much more QBasic-style structured programming: full SELECT CASE blocks (value lists, TO ranges, CASE IS comparisons), every form of DO...LOOP with EXIT DO, multiline IF/ELSEIF blocks, and user-defined TYPE records with arrays and random-record file I/O.

2026-10-03

Numeric expressions are now compiled when a program loads, and procedure variable lookups are cached. The 10-million-iteration basica.bas benchmark dropped from about 1.17 s to 0.65 s. A pre-commit hook now guards against performance regressions.

2026-10-03

PLAY gained foreground/background playback, articulation modes, volume, and tempo control, and PSET, LINE, and PAINT now take optional alpha values. A new --no-audio flag keeps automated tests fast.

2026-10-02

Version 0.99.5: errors in programs without line numbers now report the real source-file line. Side-effect-free DEF FN bodies compile once to an AST, cutting a 2-million-call benchmark from 0.99 s to 0.64 s.

2026-09-23

Added QBasic SUB and FUNCTION procedures with local scope, recursion, pass-by-reference and pass-by-value parameters, plus CALL, DECLARE, SHARED, and STATIC.

2026-09-01

Strings moved to heap-backed storage that grows on demand, so multi-megabyte values work. Fixed-length STRING * n declarations were added, and _DEFLATE$/_INFLATE$ handle large round trips.

2026-08-19

Added _LOADIMAGE, _PUTIMAGE, and _FREEIMAGE on top of SDL3_image, and improved _LOADFONT rendering with crisp nearest-neighbor glyphs.

2026-07-06

Line numbers became optional. Programs can now jump to named labels, and WINDOW and VIEW provide logical coordinates and viewport clipping for every drawing command.

2026-06-17

Added a --headless mode so graphics programs and screenshots can run in CI, and refactored the interpreter core and variable lookups for a 2× speedup.

2026-06-09

First commit of the core interpreter, followed within days by PAINT, DRAW, standard BASIC error codes with ERR/ERL, type suffixes, DEFINT-style defaults, and the SCREENSHOT command.
